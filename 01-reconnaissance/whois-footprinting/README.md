## 🎯 Objective
To perform WHOIS footprinting to gather domain registration and ownership information of a target domain.

## 🛠 Tools Used
- whois (Kali Linux command-line tool)

## 📌 Steps Performed
1. Selected a target domain (example.com)  
2. Executed WHOIS query using Kali Linux terminal  
3. Collected registrar, nameserver, and IP range details  
4. Analyzed publicly available domain records  

## ✅ Result
Successfully retrieved domain ownership information, DNS records, and network details of the target domain.

## ⚠️ Security Impact
WHOIS data exposes infrastructure and registration information which can help attackers in planning further attacks.

## 🛡 Prevention & Mitigation
- Enable domain privacy protection  
- Minimize publicly exposed registration details  
- Monitor domain information regularly
