# ⚔️ Gaining Access (Exploitation Phase)

This phase focuses on exploiting discovered vulnerabilities to gain unauthorized access to target systems in a controlled lab environment.


## 🎯 Objective

To exploit vulnerable services, applications, and weak credentials in order to gain system access and demonstrate real-world attack scenarios.


## 🛠 Tools Used

- Metasploit Framework  
- searchsploit  
- netcat  
- Web browsers  
- Linux command-line tools  


## 📌 Steps Performed

1. Identified exploitable vulnerabilities from scanning results  
2. Selected appropriate exploits for vulnerable services  
3. Executed exploits to gain unauthorized access  
4. Obtained shell access on target systems  
5. Accessed files and system resources  


## ✅ Result

Successfully exploited vulnerable services and applications to gain access to target systems within the lab environment.


## ⚠️ Security Impact

Successful exploitation allows attackers to execute commands, access sensitive data, and fully compromise systems.


## 🛡 Prevention & Mitigation

- Patch vulnerable services  
- Disable unnecessary services  
- Use strong authentication  
- Apply secure configurations  
- Regular security testing  


📂 Each subfolder contains detailed exploitation labs with step-by-step execution and evidence.
