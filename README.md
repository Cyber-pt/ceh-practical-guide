**CEH Practical Guide 🛡️**

This repository contains a complete collection of hands-on **CEH Practical** labs,
organized according to the real-world **Ethical Hacking Phases**.

The purpose of this repository is to demonstrate practical cybersecurity skills
including reconnaissance, exploitation, post-exploitation, and defense techniques.


## 🔐 Ethical Hacking Phases Covered

1. Reconnaissance (Information Gathering)
2. Scanning & Enumeration
3. Gaining Access
4. Maintaining Access & Post-Exploitation
5. Covering Tracks & Anti-Forensics
6. Sniffing & Network Monitoring
7. Advanced & Miscellaneous CEH Labs

## 🧪 What Each Lab Contains

Each lab folder includes:

- Objective of the lab
- Tools used
- Step-by-step procedure
- Screenshots (proof of execution)
- Results / findings
- Security impact
- Prevention & mitigation techniques
